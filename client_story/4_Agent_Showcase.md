# Client Storyline: Agent Showcase

## Scene 1 – Introduce the Scenario (1 min)
1. Navigate to the “Agent Showcase” page from the sidebar.
2. Highlight the banner summary: Meridian Financial Group, 247 servers, $4.2M budget.
3. Set expectations: “We’ll simulate how the agents collaborate across discovery, assessment, planning, and Quick Assess.”

## Scene 2 – Discovery Agent Tab (3 min)
1. Explain that the agent first connects to the data center and scans infrastructure.
2. Start the simulation; narrate the progress steps (connecting, topology scan, mapping apps).
3. When metrics appear, emphasize the depth: 247 servers, 156 apps, 42 DBs, 1,847 dependencies.
4. Open the “Sample Applications” grid to show how each workload is classified (tier, complexity, dependencies).
5. Key takeaway: “Discovery produces a clean inventory and dependency graph automatically.”

## Scene 3 – Assessment Agent Tab (3 min)
1. Switch to the Assessment tab; describe how it analyzes readiness and cost impacts.
2. Run the progress steps; talk through “Analyzing complexity,” “Calculating readiness,” etc.
3. Highlight the resulting metrics: readiness score, migration timeline, Year-3 savings.
4. Expand the 6Rs donut chart and describe how workloads fall into rehost/replatform/refactor/retire.
5. Key takeaway: “Assessment translates raw discovery data into readiness scoring and modernization strategy.”

## Scene 4 – Planning & Artifacts Tab (4 min)
1. Move to the Planning tab; mention this agent sequences the migration into waves.
2. Narrate the planning steps (dependencies, sequencing, rollbacks, artifact generation).
3. Show the wave metrics + table (wave name, duration, app counts, risk).
4. Scroll to the “Generated Artifacts” section and click “Generate Wave Plan” or “Generate Strategy.”
5. Open the preview/markdown to show that tangible deliverables (wave plan, strategy doc) are produced instantly.
6. Key takeaway: “Planning agent turns insights into an execution-ready plan plus downloadable artifacts.”

## Scene 5 – Quick Assess Tab (4 min)
1. Introduce Quick Assess as the rapid-entry workflow that ingests documents and diagrams.
2. Point out the uploaded evidence table (DOCX, PDF, Visio, draw.io) and the workflow timeline animation.
3. Walk through the metrics row: readiness score, number of docs/diagrams, entities extracted.
4. Show the risk bar chart, technology stack snapshot, and top recommendations.
5. Expand the JSON output to demonstrate structured data for downstream systems.
6. Key takeaway: “Quick Assess delivers insight in minutes, even before deep discovery begins.”

## Scene 6 – Close (2 min)
1. Summarize how the four tabs reflect the real-world pipeline: Discovery → Assessment → Planning → Quick Assess booster.
2. Emphasize that the same agents power their actual environment; this view simply simulates a client-ready scenario.
3. Invite next steps: “Bring your documents for a Quick Assess run, or kick off a project so we can run the full workflow together.”
